About project:

'Phone catalog'

Nice Gadgets Store is an online platform designed to provide customers with the latest mobile phones, tablets, and accessories. The store features a sleek and user-friendly interface, making it easy for visitors to explore new arrivals, browse products by category, and take advantage of exclusive discounts.
With a focus on delivering a seamless shopping experience, the website showcases high-quality images, detailed product descriptions, and intuitive navigation. Users can effortlessly add items to their cart or favourites list.
Additionally, Nice Gadgets Store highlights trending technology, promotional deals, and top-selling products to help customers make informed decisions. The platform combines convenience and innovation to ensure a modern, efficient, and engaging online shopping experience.

Getting Started:

- clone the repository:
  git clone https://github.com/Shevchuchka/react_phone-catalog.git
  cd react_phone-catalog
- install dependencies:
  npm install or yarn install
- run the project locally:
  npm start or yarn start

Features:
- Responsive design - optimized for different screen sizes and devices, responses on width 320px, 640px, 1200px
- Navigation: react-router-dom is used for navigating between pages and preserving search parameters in the URL
- Favorites & Cart: Adding products to favorites or the cart, with a total price calculation
- Product Filtering: Filtering products by capacity and color within the product card
- Sorting: Sorting products by criteria such as year, price, and alphabetical order
- Search: Filtering products by search query
- Pagination: Navigating large product lists with an option to choose the number of products per page
- Sticky Header: Keeping the header fixed while scrolling
- Scroll to Top Button: A button for returning to the top of the page
- Loader: A loading indicator for an improved user experience
- Animated effects - smooth transitions, guidance effects and interactive elements to improve UX.
- Simplified Mode - the focus on the main functions is the use of simplified shapes, large buttons, intuitive design.
- Breadcrumbs: Show users their location within the website hierarchy.
- Footer: Provides links to important pages
